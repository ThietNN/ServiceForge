# Agent Instructions

- Approved specifications are the source of truth.
- Do not invent business requirements or architecture decisions.
- Do not write application code, migrations, Docker configuration, or runtime infrastructure without explicit authorization.
- Do not add Angular or Playwright.
- Keep implementation tasks bounded and reviewable.
- Report changed files, commands executed, verification results, and unresolved questions.
- Never claim a command or test succeeded unless it actually ran successfully.
